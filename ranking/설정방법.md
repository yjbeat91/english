# 랭킹을 구글 스프레드시트에 연결하는 방법

학생들은 지금처럼 GitHub 주소(https://yjbeat91.github.io/english/)로 앱을 열어요.
앱이 게임 점수를 뒤에서 선생님의 구글 스프레드시트로 보내고, 랭킹을 받아 와요.
학생 화면에 구글 페이지나 확인창이 뜨지 않아요.

처음 한 번만 설정하면 돼요. 약 10분 걸려요. 컴퓨터에서 하는 걸 추천해요.

## 1. 스프레드시트 만들기
1. 구글 드라이브에서 **새로 만들기 → Google 스프레드시트**를 눌러요.
2. 이름을 `영단어 놀이터 랭킹`으로 바꿔요.

## 2. 코드 붙여 넣기
1. 스프레드시트 메뉴에서 **확장 프로그램 → Apps Script**를 눌러요.
2. 편집기에 원래 있던 `function myFunction() { ... }`을 모두 지워요.
3. 이 저장소의 `ranking/Code.gs` 내용을 전부 복사해서 붙여 넣어요.
   - 주소: https://github.com/yjbeat91/english/blob/claude/happy-cerf-dynn3b/ranking/Code.gs
   - 파일 화면 오른쪽 위의 복사 버튼을 누르면 전체가 복사돼요.
4. 디스크 모양 **저장** 버튼을 눌러요.

## 3. 웹 앱으로 배포하기
1. 오른쪽 위 **배포 → 새 배포**를 눌러요.
2. "유형 선택" 옆 톱니바퀴를 누르고 **웹 앱**을 골라요.
3. 아래처럼 설정해요.
   - **다음 사용자 인증 정보로 실행:** 나
   - **액세스 권한이 있는 사용자:** 모든 사용자
4. **배포**를 눌러요.
5. "액세스 승인" 창이 뜨면 이렇게 진행해요.
   1. 선생님 구글 계정을 고르고 **고급**을 눌러요.
   2. **(안전하지 않은 페이지로) 이동**을 눌러요. 선생님이 직접 만든 코드라서 나오는 정상적인 안내예요.
   3. **허용**을 눌러요.
6. 마지막 화면의 **웹 앱 URL**을 복사해요. `https://script.google.com/macros/s/.../exec`처럼 생겼어요.

## 4. 주소를 Claude에게 알려주기
복사한 웹 앱 URL을 대화창에 붙여 넣어 주세요.
제가 앱의 `RANK_URL`에 넣어서 GitHub에 올리면, 몇 분 뒤부터 모든 학생의 기록이 시트에 모여요.

## 관리하기
- 기록은 스프레드시트의 `scores` 시트에 한 판에 한 줄씩 쌓여요.
- **장난 기록 지우기:** 그 줄을 삭제하면 랭킹에서 바로 빠져요.
- **랭킹 새로 시작하기:** 첫 줄(제목)만 남기고 나머지 줄을 지워요.
- **코드를 바꾼 경우:** Code.gs를 고친 뒤에는 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 해야 반영돼요. 웹 앱 URL은 그대로예요.
